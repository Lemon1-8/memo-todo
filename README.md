# Memo ToDo

一个个人使用的 Windows 桌面待办小组件，使用 Electron、Vite、React 和 TypeScript 构建。

## 功能

- 半透明深色待办小窗口
- 托盘显示、隐藏和退出
- 置顶开关
- 开机启动开关
- 本地 JSON 保存任务和设置
- 一次性提醒，支持 Windows 通知
- 中文快捷输入提醒时间
- 显式编辑任务标题、提醒时间和优先级
- 待办、进行中、等待、已完成四种任务状态
- 搜索、状态筛选和优先级筛选
- 完成项归档、归档恢复和删除撤销

## 快捷输入

在底部输入框回车即可新增任务。

支持这些提醒格式：

```text
今天 14:00 写周报
明天 09:30 整理客户
2026-09-10 18:00 健身
```

## 第二版手动验收

- 搜索可以按标题过滤任务，清空搜索后恢复当前状态列表
- 状态筛选可以切换未完成、待办、进行中、等待、已完成、全部和归档
- 每条任务可以直接切换待办、进行中、等待和已完成状态
- 优先级按钮可以在普通、高、低之间切换，列表按高、普通、低优先级排序
- 切换到全部时，未完成任务排在前面，已完成任务固定在最下面
- 提醒按钮可以设置、修改和清除提醒时间
- 归档按钮可以隐藏任务，归档视图可以恢复任务
- 删除任务后底部出现撤销入口，8 秒内可以恢复最近一次删除

## 打包 Windows Portable

```bash
npm run dist
```

打包产物会生成在 `release/`，该目录不会提交到 Git。

## 数据位置

应用数据保存在 Electron 的 `userData` 目录下，文件名为 `memo-todo.json`。当前版本不包含账号、云同步或联网依赖。
